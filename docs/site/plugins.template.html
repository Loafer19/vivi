Plugin catalog

plugins. Built-in plugins ship with Vivi; enable them in Settings → Extensions. Downloadable plugins install with one click from Settings → Extensions → Browse, are checked against their sha256 and update themselves. mpv scripts go in ~/.config/vivi/scripts. Machine-readable list: index.json · how distribution works.

Want yours listed? Read Write a plugin and open a pull request to vivi-plugins that adds a plugins/<id>/ package (see Package & publish).
