A media player that gets out of the way

Vivi is a fast, lightweight desktop player written in Rust on top of mpv, with a clean interface by default and deep customization when you want it.

Download Browse plugins

Features

Everything mpv plays, in a UI based on the Figma “VLC Redesign”.

Plays everything

libmpv with hardware decoding, Wayland and X11, subtitles, chapters, A-B loop, speed and filters.

Library

Continue Watching, music by artists and albums, folders, playlists, network streams and thumbnails.

Music visualizer

Spectrum, scope, waveform, radial, particles and pitch visuals for audio files.

Plugins

Skip intros, karaoke lyrics, subtitle search, plus any mpv Lua or JavaScript script.

Remembers

Resume positions, per-show presets for delays and track languages, recent files.

Everywhere

AppImage, Arch packages, Windows and macOS builds; MPRIS media keys on Linux.

Plugins

Turn them on and off in Settings → Extensions. See the catalog →

Install

# Arch / Omarchy
git clone https://github.com/Loafer19/vivi && cd vivi
sudo pacman -S --needed mpv rust
cargo build --release && ./target/release/vivi

Prebuilt AppImage, tarball, Windows and macOS builds are on the releases page.
