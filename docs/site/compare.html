Six alternatives worth knowing.

mpv

Choose it if

You want deep video configuration.

Much smaller on disk than Vivi and close to it in idle memory, with a huge collection of user scripts and the most configurable video output. Vivi itself is built on libmpv.

The Vivi alternative

A UI with a music library, waveform seeking, synced lyrics and an auto-tagger.

VLC

Choose it if

You need mobile, discs or devices.

Lowest idle memory and fastest start in our test, runs on nearly every platform including mobile, and plays discs and devices that Vivi does not target.

The Vivi alternative

Waveform seeking, synced lyrics, an auto-tagger and an MCP server.

foobar2000

Choose it if

Audio tools come first.

Long audio-focused polish: CD ripping, transcoding, a deep DSP chain, advanced tagging and a large component ecosystem. Vivi now has gapless playback, ReplayGain and crossfade too, but not the rest. Not open source, and no video.

The Vivi alternative

Video playback, a free music catalogue and an in-app plugin marketplace.

IINA

Choose it if

You want a truly native Mac app.

A truly native macOS app with trackpad gestures, Picture in Picture and Live Text. Vivi's macOS build is unsigned and best effort.

The Vivi alternative

Linux and Windows support, plus an auto-tagger and free music catalogue.

MPC-HC

Choose it if

You prefer the Windows classic.

A mature Windows classic built on the DirectShow / LAV filter ecosystem.

The Vivi alternative

Linux and macOS support, plus an in-app plugin marketplace and auto-tagger.

Celluloid

Choose it if

You want mpv to feel at home in GNOME.

Opens its window slightly faster than Vivi from a cold cache in our test (~0.73 s against ~0.77 s; warm, Vivi is ahead at ~0.27 s against ~0.35 s), fits right into GNOME with GTK, MPRIS and Wayland support, and reads your existing mpv config files as-is.

The Vivi alternative

A music library, waveform seeking, synced lyrics and online subtitle search.

How we measured · complete conditions & exclusions

Size was measured on 27 Oct 2026 (v0.15.0); start time, memory and CPU on one desktop under identical conditions on 18 Oct 2026. Numbers appear only where we measured them.

  • Download: size of the v0.16.1 Linux tarball from the published release (18,996,654 bytes, still 19.0 MB). mpv and VLC on Linux come from distribution packages, so there is no single download to compare.
  • Installed size: Vivi = the files the installer copies (vivi, vivi-mcp, desktop file and icons), excluding the system libmpv. mpv and VLC = the Installed-Size of their Debian 13 packages (mpv + libmpv2; vlc, vlc-bin, vlc-plugin-base, vlc-plugin-qt, libvlc5, libvlccore9), excluding shared libraries such as FFmpeg and Qt. Celluloid = the Installed Size of the Arch Linux package celluloid 0.30-2 (1,191 KiB, measured 18 Oct 2026), excluding libmpv and GTK.
  • Start time, memory and CPU: Arch Linux, Hyprland (Wayland), NVIDIA RTX 3060 Ti, 12-core CPU, 16 GB RAM; each player with its normal configuration on that PC. Vivi = the v0.16.2 branch built with the ci profile (release optimizations without fat LTO), measured on 10 Nov 2026 in a fresh test profile (default settings, audio output off, no network, its own Wayland output); the cold start is still the v0.12.0 figure from 18 Oct 2026. Measured the same way, v0.12.0 used ~229 MB idle and ~299 MB playing. mpv 0.41 (--idle --force-window=yes), VLC 3.0.23 (Qt interface), Celluloid 0.30 (GTK 4, on the same libmpv 0.41, default settings). Time runs from launch to the first Wayland surface attach (WAYLAND_DEBUG=1, polled every 20 ms); VLC 3 draws through XWayland, so for VLC it is the time until its window is mapped (hyprctl clients). Warm = median of 3 runs; cold = after echo 3 > /proc/sys/vm/drop_caches. Memory is PSS of the main process from /proc/PID/smaps_rollup 3 s after the window appears, idle (nothing opened) or playing a local 1080p H.264 clip (1080×1920, 30 fps); CPU is the average over 10 s of that playback (100% = one core). Vivi and VLC decode on the GPU there; mpv and Celluloid use software decoding unless hwdec is set. Celluloid playing memory is the mean of 2 runs (531 and 604 MB).
  • MPC-HC, IINA and foobar2000 do not run natively on Linux, so no numbers are shown for them.
